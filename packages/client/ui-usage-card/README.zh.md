# @deepseek-ai/dsh-client-ui-usage-card

[English](README.md) | 中文

**侧边栏用量仪表盘卡片**：占据 `sidebar.footer.action` 列表槽位，渲染在侧边栏底部**设置按钮上方**，两种宽度都支持——侧边栏展开时显示完整卡片，收成 56px 窄栏时显示一个紧凑的"时段圆点 + 余额"小胶囊。

卡片展示：

- **余额** —— 来自 `billing.balance`，由宿主侧（[dsh-host-billing](../../host/billing/README.md)）代为请求，API 密钥不会进入浏览器。
- **峰谷时段** —— 按 DeepSeek 官方峰谷窗口计算（高峰：北京时间 09:00–12:00、14:00–18:00；其余空闲时段半价）；谷时段显示绿色"谷 · 半价"徽标。7 日柱状图按天堆叠峰（灰）/谷（绿）金额。
- **今日 Tokens / 今日金额** —— 来自 `billing.today`，按配置的价目表逐事件计价的估算值（金额为估算，卡片上已标注）。

数据每 60 秒通过 `/billing` 回环 RPC 通道轮询（重连后立即刷新），由小型共享 store 驱动；点击卡片可手动刷新。

## Model Experience

无；卡片是纯 GUI，不触达模型请求。

#### KV Cache 影响

无；本包既不组装也不发送提供商请求。

## 已知限制与后续工作

- **估算币种** —— 金额按宿主的默认价目表以余额币种计价；部署单价不同时配置 `dsh-host-billing` 的 `pricing`。
- **时段徽标最多滞后一个刷新周期** —— 徽标在每次 store 更新（每 60 秒）时重算，时段切换后一个刷新周期内更新。
